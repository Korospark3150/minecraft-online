Minecraft ローカルマルチプレイ版（JSON保存）

【必要なもの】
・Node.js（ZIP版でもOK）
・インターネット接続（初回の ws パッケージ導入時）

【初回だけ行うこと】
1. このフォルダを好きな場所に展開します。
2. このフォルダ内でコマンドプロンプトを開きます。
3. Node.js のフォルダを一時的に PATH に追加します。
   例：
   set "PATH=C:\\tools\\node;%PATH%"
   ※ C:\\tools\\node は node.exe と npm.cmd がある実際の場所に置き換えてください。
4. 次を実行します。
   npm install

【サーバーを起動するとき】
このフォルダ内で次を実行します。
   npm start

ブラウザで http://localhost:3000 を開いてください。
同じPCで2人分を試す場合は、別ウィンドウでも同じURLを開き、同じ部屋IDに参加します。

【別のPCから参加】
同じWi-Fi内のPCなら、サーバーPCのIPアドレスを使って
   http://サーバーPCのIPアドレス:3000
を開きます。

【ワールド保存】
ワールドデータは、このフォルダ内の worlds フォルダに部屋ごとの JSON ファイルとして保存されます。
サーバーを停止してもファイルは残ります。worlds フォルダや JSON ファイルを削除すると、その部屋の保存データも消えます。

【補足】
・SQLite / better-sqlite3 は使用しません。
・PythonやVisual StudioのC++ビルドツールは不要です。
・WebSocket通信に ws パッケージを使用します。
・この構成はまずローカルまたは同じWi-Fi内でのテスト用です。インターネットに直接公開する前に認証・通信保護などの対策が必要です。
